# Shopigent Stock — Quick Start Guide

Shopigent Stock replaces Stocky (shut down August 2026). It handles everything: bundles, auto inventory deduction, warehouse tracking, AI forecasting, and purchase orders. Here's how to get started.

## Install the App

1. Visit the [Shopify App Store](https://apps.shopify.com/shopigent-stock) and click **Install**
2. Review the permissions (products, orders, inventory) and approve — required for auto-deduction to work
3. After installation, the app opens to your Dashboard

**What you'll see right away:** A dashboard showing your inventory snapshot, recent orders, and a shortcut to create your first bundle.

## Create Your First Bundle — Under 5 Minutes

1. Click **Smart Bundles** → **Create bundle**
2. Give it a name (e.g., "Tea Sampler")
3. Search for products to add as components — choose the items that make up this bundle
4. Set a price — flat price, percentage off, or volume discounts
5. Click **Publish as Shopify product** → **Create bundle**

That's it. The bundle now appears as a product in your store. Customers can buy it like any other item.

## Add a Storefront Widget in 3 Minutes

1. Go to **Storefront Widgets** → **Create widget**
2. Select your bundle
3. Pick where it appears (near the buy button, below description, etc.)
4. Choose a template (Compact Bar, Gallery Card, etc.)
5. Open your theme editor → Add the **Bundle Widget** block → enter the widget key → Save

## Main Features at a Glance

| Feature | How to use |
|---|---|
| **Auto-deduction** | Place a test order — component inventory drops automatically |
| **Mix & Match** | Enable in bundle editor, set minimum picks — storefront shows a picker |
| **Forecasting** | Go to AI Forecasting → Load inventory → see days-until-stockout per item |
| **Warehouse** | Create shelves (Line·Section·Shelf·Position) → assign products → print barcodes |
| **Purchase Orders** | Go to Purchasing → Create PO → add items → mark Ordered → Receive when stock arrives |

## Troubleshooting

**Widget not showing on your storefront?** Check that the widget is enabled in the app and the widget key is entered correctly in your theme editor. Make sure the theme extension is published.

**Bundle deduction not working?** Verify your bundle has components assigned and your store has inventory at the location you're using.

**Inventory not updating?** Make sure a Shopify location exists and the app has permission to manage inventory there.

**Need help?** Contact support from the Dashboard — we respond within hours, not days.
